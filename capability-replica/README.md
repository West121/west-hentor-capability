# Capability Replica

This directory contains a privacy-safe copy of the Capability Table system.

## Stack

- Frontend: React, TypeScript, Vite, Ant Design, Tiptap.
- Backend: Java 21, Spring Boot, Maven.
- Data: SQL Server database `sgsmineralscapability` imported from the production SQL dump.

## Run

```bash
cd backend
mvn spring-boot:run
```

```bash
cd frontend
npm install
npm run dev
```

Frontend defaults to `http://localhost:5173`; backend defaults to `http://localhost:9901`.
The backend default store mode is `database` and reads/writes SQL Server through `spring.datasource.*`.
